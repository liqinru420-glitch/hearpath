HearPath｜听见成长

0—14岁儿童听力健康观察与家庭支持平台

在线体验： https://liqinru420-glitch.github.io/hearpath/

一、项目简介

HearPath 是一款面向0—14岁儿童家庭的听力健康观察与就医准备Web平台。

项目关注尚未接受专业听力评估、但家长已注意到听觉反应或语言沟通方面疑问的儿童家庭。

平台通过分年龄动态问卷、家庭情境观察、多条件规则分析和可视化报告，帮助家长整理孩子的日常表现、了解需要关注的信息，并为后续专业评估提供参考。

平台不替代正规医学筛查、疾病诊断或治疗。

二、核心功能

1. 分年龄动态问卷

针对0—14岁儿童设计九组不同问卷，覆盖婴儿早期声音反应、幼儿语言沟通、学龄儿童课堂听讲及青少年听觉变化等方面。

2. 多维度健康信息记录

记录日常听觉表现、语言理解与表达、孕期及出生健康史、既往疾病、家族听力健康史等信息，并通过条件分支减少不必要的问题。

3. 家庭情境式观察

支持记录自然交流中的环境、距离、注意状态及孩子的回应情况，帮助家长描述不同情境下的表现。

4. 多条件规则分析

系统根据问卷答案整理主要关注方向、分析依据和待核实信息，生成差异化反馈。

分析结果不代表疾病诊断、患病概率或听力损失程度。

5. 可视化观察报告

生成包含观察概览、主要关注方向、行动建议和就医准备清单的报告，支持复制摘要及浏览器PDF导出。

三、技术架构

HTML5：网页结构与内容组织

CSS3：响应式布局和视觉设计

JavaScript：交互问卷、动态条件分支与规则分析

GitHub Pages：网站静态部署

平台主要功能在浏览器端运行，无需数据库、独立后端服务器或大语言模型API。

四、项目创新点

分龄差异化设计： 根据儿童不同发展阶段呈现相应的观察内容。

多维信息整合： 将听觉行为、语言沟通、健康史与家庭情境记录整合到同一交互流程。

可解释规则分析： 报告不仅呈现关注方向，还解释相关问卷依据和后续建议。

从观察到行动： 将零散的家长观察整理为便于专业人员沟通的就诊准备资料。

五、运行方式

项目包含三个核心文件：

index.html：网页页面结构

style.css：页面视觉样式

app.js：问卷、分析及报告逻辑

下载源代码后，可直接使用浏览器打开 index.html。

也可在项目目录运行：

python3 -m http.server 8000

然后访问 http://localhost:8000。

六、隐私与安全

当前版本不设置用户账号或后端数据存储。问卷信息在当前浏览器页面内存中处理，刷新后清除。

项目不建议用户填写儿童姓名、联系方式、完整病历等可识别身份的信息。

七、项目声明

本项目为数字媒体科技作品竞赛演示原型，问卷内容与规则尚未经过临床验证或正式专业审核。

所有观察报告仅用于健康信息理解和就医准备，不构成医学筛查、诊断或治疗建议。正式用于真实家庭前，仍需进一步进行专业审核和测试。
