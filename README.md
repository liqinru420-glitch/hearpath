# HearPath｜听见成长

**0—14岁儿童听力健康观察与家庭支持平台**

**在线体验（正式）：** https://hearpath-observe.netlify.app/

HearPath 面向尚未接受专业听力评估、或对孩子日常听觉与语言沟通表现存在疑问的家长。通过分年龄动态问卷、家庭情境观察、多条件规则分析与可视化报告，帮助家长整理观察资料、理解需要关注的信息，并为后续就医沟通做好准备。

## 已实现的功能

- 九组年龄段问卷（0—14岁）与条件跳题。
- 听觉反应、语言沟通、孕期及出生健康史等多维度信息记录。
- 可选的自然家庭情境观察模块。
- JavaScript 规则分析、多关注方向报告、行动清单及 PDF 打印。
- 现代浏览器及手机端响应式访问。

## 技术与部署

- `index.html`：网页结构。
- `style.css`：网页样式与打印样式。
- `app.js`：问卷题库、规则分析、动态报告。
- **正式演示平台：Netlify**，公开网址：https://hearpath-observe.netlify.app/
- **源代码管理：GitHub**。

本地运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 重要说明

本作品为数字媒体竞赛演示原型，**不是医学诊断或专业听力筛查工具**。问卷及规则尚未经过临床验证和正式专业审核，报告不能用于确诊、排除疾病或判断听力损失程度。请勿填写可识别儿童身份的敏感信息。

使用了生成式 AI 辅助开发，运行时不调用大语言模型 API。
